## What this is

The IT Support Field Guide is a free, static collection of short IT
troubleshooting articles, cheat sheets, and helpdesk basics. It is written to be
scanned quickly, so a fix can be found in under 30 seconds, from a laptop or a
phone.

It serves three purposes: a study tool while preparing for an IT support role, a
quick-lookup reference on the job, and a portfolio project afterwards.

## Who writes it

Written and maintained by a trainee IT support technician as a learning and
reference project.

## No employer information

This site contains only generic knowledge drawn from public vendor documentation
and personal lab testing. It holds **no company-specific or confidential
information**: no real names, hostnames, IP addresses, domains, or internal
procedures. Placeholders such as `contoso.com` and the documentation IP range
`192.0.2.0/24` are used throughout.
