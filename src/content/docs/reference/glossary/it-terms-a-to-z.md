## In one sentence

A plain-English list of the terms and acronyms you will hear on the helpdesk, so
no one has to pretend they already know them.

## How it works

Each entry gives the term, what it stands for, and a one-line explanation. This
page grows as new terms come up on real tickets.

| Term | Stands for | What it means |
|---|---|---|
| AD | Active Directory | Microsoft's on-premises directory for users, computers, and groups. |
| DHCP | Dynamic Host Configuration Protocol | Hands out IP addresses to devices automatically. |
| DNS | Domain Name System | Translates names like `example.com` into IP addresses. |
| MFA | Multi-Factor Authentication | A second proof of identity beyond a password. |
| SLA | Service Level Agreement | The agreed time to respond to or resolve a ticket. |

## Why it matters on the helpdesk

Shared language keeps tickets clear and handovers clean. When everyone means the
same thing by "MFA" or "SLA", problems get solved faster.
