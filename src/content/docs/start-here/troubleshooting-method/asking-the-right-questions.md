## Before you start

- Have the ticket open so you can note answers as you go.
- Decide you will listen first and fix second. The questions come before the
  keyboard.

## Steps

1. Ask the user to describe the problem in their own words, and let them finish.
2. Pin down **what** happens: the exact error text, or a photo of the screen.
3. Pin down **when**: does it happen every time, or sometimes? When did it start?
4. Pin down **scope**: just this user, or others too? One app, or everything?
5. Ask **what changed**: a password change, an update, a new device, a house move.
6. Ask what they have already tried, so you do not repeat it.
7. Read the facts back to confirm you understood before you act.

:::tip
"What changed recently?" is the single most useful question on the helpdesk.
Most problems trace back to a recent change.
:::

## Verify it worked

- You can state the problem in one sentence, with the exact error and its scope.
- You know what changed and what the user has already tried.
- If you cannot, you have more to ask before you start fixing.
